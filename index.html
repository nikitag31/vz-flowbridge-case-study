The Problem

Launching a retail or digital promotion today is manual, siloed, and slow. Three friction points compound the delay.

  • Information asymmetry — PRDs live on AYS, visible mainly to Associate Directors and above; designers, engineers, and product owners are blocked from the requirements they're expected to build against.
  • Manual alignment meetings — identifying impacted channels (Digital, Retail, ACSS) and pods (Storefront, Billing, Line Config, Support) takes sequential meetings, overhead that compounds with every lead added to the room.
  • The translation tax — handing static Figma files to developers routinely introduces bugs, layout drift, and accessibility deviations from the design system.
Why it matters

Past N = 12 organizational pods, coordination channels degrade into noise — meetings stop resolving ambiguity and start creating it.

The Approach

VZ Flowbridge is a unified, multi-directional workspace where any employee can ingest requirements, inspect interactive flows, toggle viewport formats, and retrieve code — without waiting on a design sprint.

  • AI-driven requirements ingestion — pulls directly from AYS/Jira or parses raw uploaded documents using semantic classifiers trained on telecom taxonomy.
  • Service blueprint synchronization — highlights frontstage actions, backstage microservices, and third-party APIs involved in the selected user journey.
  • Instant design iterations ("vibe coding") — team members change visual directions or inject localized layout variations via raw natural language instructions.
  • Direct code delivery — generates clean, well-commented React/Tailwind code using native VDS parameters, for immediate frontend integration.
Design principle

Predictable, VDS-compliant, always. Every generated screen sources tokens from the same system a hand-built one would — there is no second, informal design language to drift from.

Persona Ecosystem

VZ Flowbridge addresses the workflows of diverse organizational stakeholders through a single shared touchpoint per role.

  • Product Strategy — instantly validates feasibility and visualizes layouts without booking design sprints, via the Ingestion Panel & Interactive Flow.
  • UX/UI Designers — offloads repetitive high-volume screen variations to focus on core journey maps and accessibility standards, via the AI Design Iterations Panel.
  • Frontend Engineers — bypasses the manual redlining step with instant access to functional VDS-compliant React code, via the Code Handover Workspace.
  • Business Stakeholders — obtains complete transparency into which internal systems and databases are impacted by promotions, via the Service Blueprint Matrix.

Future Enhancements & Learnings

VZ Flowbridge is a conceptual platform built for this recruitment exercise — here's where it would go next, and what building the case study itself surfaced.

Future enhancements
  • Multi-brand tokenization — extend the VDS tokenizer to sub-brands and white-label storefronts without a manual re-skin pass.
  • Confidence-score learning loop — feed manual corrections back into the pod matcher so match confidence improves release over release.
  • Native Slack ingestion — parse scoping discussions directly from a thread, not just formal Jira/AYS documents.
  • Accessibility regression diffing — flag automatically when a shipped build drifts from WCAG 2.1 AA relative to the approved prototype.
  • Figma reconciliation plugin — detect drift between a designer's working file and the tokenizer's source of truth.
What I learned
  • Quantify the pitch. Working out the Co formula and the 99.8% efficiency gain forced a concrete business case instead of a vague "this will be faster" claim.
  • Show, don't tell. An early draft of this case study was mostly prose — walking one real scenario screen-by-screen communicated the platform faster than the paragraphs describing it.
  • Scope the claims honestly. The pod-matcher confidence scores and semantic classifiers here are illustrative, not benchmarked against real telecom taxonomy data.
  • Mockups over screenshots. The working prototype was built and run locally on a separate machine; the visuals throughout this page are recreated mockups, presented as such.

Outcome

VZ Flowbridge collapses a 48-hour manual promo-launch cycle into a 5-minute, VDS-compliant one — eliminating manual design deviations, the handover back-and-forth between design and engineering, and the coordination overhead that scales with every pod added to a launch.

For me it was a chance to design a full requirements-to-code pipeline end to end: framing the business case with real formulas, tracing one concrete scenario through every platform pillar, and being honest in the write-up about what's demonstrated versus what's illustrative.

About this case study

VZ Flowbridge is a conceptual, organization-level Gen AI platform prepared for Salesforce's Senior UX/UI & Product Strategy recruitment process. It demonstrates how large-scale enterprise platforms — Salesforce's Agentforce among them — can leverage predictive AI models to orchestrate mission-critical workflows.
